# Projeto TypeScript - Guia de Execução

Este repositório contém uma aplicação desenvolvida em **TypeScript**, estruturada para execução em ambiente Node.js. Siga as instruções abaixo para configurar e rodar o projeto corretamente em sua máquina.

---

## 📋 Pré-requisitos

Certifique-se de ter as seguintes ferramentas instaladas em seu sistema antes de prosseguir:
* **Node.js** (versão 18.x ou superior recomendada)
* **npm** (geralmente instalado junto com o Node.js) ou **Yarn** / **pnpm**

Para verificar se o Node e o npm estão instalados, execute no seu terminal:
```
node -v
npm -v
```

---

## comando para roda o projeto na pasta raiz:
```
npx vitest run
```
